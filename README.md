# CV Generator

A browser-only CV builder. Fill in the form on the left, and the preview on the right updates live.

- Four templates (Coral Diagonal, Minimal Mono, Ocean Blue, Forest Sidebar)
- Click any section in the preview to change its font, size and colour, or reorder it
- Optional photo, background colour picker
- Export to PDF (html2canvas + jsPDF)

No server, no accounts, no API keys. Open `cv-generator.html` in a browser.
